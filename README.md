# 🧟 감염 대한민국 — 오픈월드 생존 시뮬

2026년, 좀비 바이러스가 퍼진 **실제 한국(17개 시도)과 세계**를 무대로 한 자유도 높은 텍스트 생존 시뮬레이션.
정해진 스테이지·시나리오 없이, 어디든 가고 무엇이든 하며 **그저 살아남는** 샌드박스입니다.
당신에겐 오직 자신만 보는 「시스템(상태창)」 능력이 있습니다. StackBlitz에서 바로 실행됩니다.

## 자유도

- **실제 지리**: 서울·경기·부산·제주 등 17개 시도를 실제 인접 관계로 이동. 인천공항·부산항 등에서 **일본·중국·러시아**로 항해.
- **장소 유형**: 주택가·대형마트·약국·종합병원·군부대·경찰서·역·공장·주유소·번화가·연구소 등. 유형마다 물자와 위험이 다름.
- **자유 행동**: 수색 · 교전(정면/신중/은밀/화염병) · 휴식 · 섭취 · 제작 · 거점화 · 이동.
- **정답 없음**: 강제 퀘스트가 없다. 거점을 키우든, 해외로 탈출하든, 백신을 쫓든 당신의 선택.

## 생존 시뮬레이션

- **시간**: 일자/시각이 흐르고 밤이 되면 위험·공포 증가.
- **욕구**: 포만 · 수분 · 기력이 닳고, 바닥나면 HP·정신이 깎인다.
- **감염도**: 물리면 상승, 방치하면 좀비화(사망). 항생제·구급킷으로 치료.
- **동적 세계**: 매일 좀비가 재유입되고 지역 감염도가 변한다. 생존자 조우·약탈자·보급·소문 등 랜덤 이벤트.

## 성장 (시스템 능력)

- 능력치: 힘·민첩·체력·감각·정신. 처치로 경험치 → 레벨업(포인트 +3, 회복, 스킬 해금).
- 스킬: 포식(Lv1·잔재 흡수로 능력치 영구 상승) · 생존본능 · 응급처치 · 도살자 · 그림자.

## 선택적 목표

소문을 통해 **국립 감염병연구소**의 위치가 드러난다. 찾아가 장악하면 **백신**을 확보할 수 있다(달성 후에도 계속 생존 가능).

## 실행
StackBlitz로 열면 자동 설치 후 `npm run dev` 실행. 로컬은 `npm install && npm run dev`.
진행 상황은 브라우저에 자동 저장되어 "이어하기"로 재개됩니다.

## 구조
- `src/types.ts` 데이터 모델 · `src/world.ts` 지리·아이템·로직데이터·월드 생성
- `src/sim.ts` 시뮬레이션 엔진(시간·생존·전투·이동·이벤트) · `src/App.tsx` UI + 상태관리
- React 18 + TypeScript + Vite, 외부 런타임 의존성 없음
