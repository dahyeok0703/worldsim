# 🌍 WorldSim — 지구 2026 편집기

현실 지구(2026년 6월 1일 기준)의 국가 정보를 **쭉 나열해 두고 자유롭게 편집**하는 웹 앱입니다.
경제 · 군사 · 영토 · 출산율 · 사회 · 인구 · 행정구역 등 어떤 정보든 직접 고치고, 항목·분류·국가를 추가/삭제할 수 있습니다.

## 특징

- **자유 편집**: 모든 값은 클릭해서 바로 수정. 라벨(항목 이름)도 편집 가능.
- **전 세계 197개국**: UN 회원국 + 주요 미승인국(대만·코소보·팔레스타인 등)을 대륙별로 수록.
- **유연한 구조**: `국가 → 분류(카테고리) → 항목(라벨:값)`. 원하는 정보 칸을 마음대로 추가.
- **대륙별 그룹**: 사이드바에서 아시아·유럽·아프리카·북미·남미·오세아니아로 묶어 탐색. 국가명·대륙 검색 지원.
- **정렬**: 인구·면적·GDP·1인당 GDP·출산율·기대수명·도시화율·인구밀도·이름 기준으로 오름/내림차순 순위 보기.
- **통계 패널**: 현재 목록 기준 총인구·총면적·GDP 합계·평균값·인구밀도와 인구/GDP 상위 5개국을 한눈에.
- **자동 저장**: 변경 즉시 브라우저 로컬(localStorage)에 저장돼 새로고침해도 유지.
- **백업/공유**: JSON 내보내기·가져오기 지원.
- **초기화**: 언제든 기본 시드 데이터로 되돌리기.

## 실행 방법

### StackBlitz
1. 이 저장소를 StackBlitz로 열면 자동으로 의존성을 설치하고 `npm run dev`가 실행됩니다.
2. 미리보기 창에서 바로 편집을 시작하면 됩니다.

### 로컬
```bash
npm install
npm run dev
```

## 기술 스택
- React 18 + TypeScript + Vite
- 외부 서버/DB 없음 (100% 브라우저 로컬)

## 데이터 안내
초기 수치(인구·면적·GDP·출산율·기대수명 등)는 2026년 기준 **근사 추정치**로,
정확한 공식 통계가 아닙니다. 앱 안에서 자유롭게 수정해 사용하세요.
국가마다 기본 분류는 **기본 / 경제 / 사회** 3종입니다.
- 기본: 수도, 인구, 면적, 정부형태, 통화, 공용어
- 경제: GDP(명목), 1인당 GDP, 주요산업
- 사회: 합계출산율, 기대수명, 도시화율, 주요종교

군사·행정구역 등은 직접 분류를 추가해 채울 수 있습니다.

> 정렬·통계는 필드 값에서 숫자를 자동으로 읽어 계산합니다. 값을 편집해도 숫자 형식(예: `81%`, `$1,950B`)을 유지하면 집계에 그대로 반영됩니다.
