# 🧟 감염도시 — 시스템 각성자

2026년 현대 지구, 좀비 바이러스가 퍼진 도시에서 **나만 보이는 게임 시스템(상태창)** 능력으로
대피소까지 살아남는 텍스트 기반 RPG. StackBlitz에서 바로 실행됩니다.

## 플레이

1. **캐릭터 생성** — 이름을 짓고 자유 능력치 5포인트를 분배.
   - 힘(공격) · 민첩(회피·도주) · 체력(HP·방어) · 감각(치명타) · 정신(스킬·공포저항)
2. **분기 스토리** — 선택지로 진행. 일부 선택지는 능력치/스킬/소지품 조건을 만족해야 열림.
3. **턴제 전투** — 공격 · 스킬 · 아이템 · 도주. 감염체를 처치해 경험치를 얻는다.
4. **성장** — 레벨업 시 능력치 포인트 +3, HP/정신 회복, 스킬 자동 습득.
   - Lv2 강타 · Lv3 응급처치 · Lv4 간파 · Lv5 질주(패시브)
   - 고유 능력 **포식**: 처치 시 드물게 능력치가 영구 상승하거나 회복.
5. **목표** — 원룸 → 거리 → 편의점/뒷골목 → 대로 → 의원 → 학교 대피소(보스 변이 포식체)까지.

진행 상황은 **브라우저에 자동 저장**되어 타이틀에서 "이어하기"로 재개할 수 있습니다.

## 실행

### StackBlitz
저장소를 열면 자동으로 의존성 설치 후 `npm run dev`가 실행됩니다.

### 로컬
```bash
npm install
npm run dev
```

## 구조
- `src/types.ts` — 데이터 모델
- `src/content.ts` — 아이템 · 스킬 · 적 · 분기 씬(스토리)
- `src/engine.ts` — 전투·성장 공식(순수 함수)
- `src/App.tsx` — 게임 상태(reducer) + UI
- React 18 + TypeScript + Vite, 외부 런타임 의존성 없음

시나리오 추가, 새 적/보스, 무기·총기(탄약), 동료 시스템, 거점 운영 등으로 이어갈 수 있습니다.
