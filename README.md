# 🗺️ WorldMap — 세계 지도 편집기

전 세계 지구 지도를 **국가별 고유 색**으로 칠하고, 각 국가의 **프로빈스(하위 행정구역)**를
같은 색으로 표시하는 편집 앱입니다. 지도를 클릭해 색·이름·소속을 자유롭게 편집할 수 있습니다.

## 특징

- **전 세계 행정구역**: 253개 국가·지역의 **4,596개 프로빈스(admin-1)**를 실제 지리 경계로 표시.
- **국가별 색 구분**: 국가 코드에서 결정적으로 생성한 고유 색. 같은 국가의 프로빈스는 자동으로 같은 색.
- **지오메트리 편집**:
  - ✏️ **새 프로빈스 그리기** — 지도에 폴리곤을 그려 새 행정구역 생성
  - ✂️ **분할** — 프로빈스 위에 영역을 그려 둘로 나눔
  - 🔗 **병합** — 여러 프로빈스를 합집합으로 하나로 합침
  - 🗑 삭제
- **선택 방식**:
  - 좌클릭 — 프로빈스 선택
  - **Alt + 좌클릭 — 국가 전체 프로빈스 선택 → 우측에 국가 상태창**
  - Shift + 좌클릭 — 다중 선택(병합용)
- **색 지정**: 프로빈스별 개별 색 또는 국가 단위 색 지정.
- **상세정보**: 프로빈스/국가마다 항목·값 형태의 상세정보를 자유롭게 추가·편집.
- **소속 이전**: 프로빈스를 다른 국가로 옮기면 색도 따라 변경.
- **탐색**: 드래그 이동, 휠·버튼 확대/축소, 국가명으로 바로 이동, 마우스오버 툴팁.
- **자동 저장**: 모든 편집을 브라우저 로컬(localStorage)에 저장 — 새로고침해도 유지.

## 기술 스택
- React 18 + TypeScript + Vite
- d3-geo (커스텀 SVG 렌더러 · 팬/줌 · 화면↔경위도 변환)
- topojson-client (지도 로딩), polygon-clipping (분할/병합 불리언 연산)
- 지도 데이터: Natural Earth 1:10m Admin-1 States/Provinces
  (mapshaper로 단순화·경량화한 TopoJSON, `public/world_provinces.topo.json`)

## 데이터 안내
국경·행정구역 경계는 Natural Earth 공개 데이터를 단순화한 것으로, 표시 목적의 근사치입니다.
분쟁 지역의 경계·귀속은 데이터 원본을 따르며 앱 안에서 자유롭게 편집할 수 있습니다.
